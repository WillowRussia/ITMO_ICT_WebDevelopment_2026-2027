## Запуск

Везде порядок один: сначала сервер, затем клиент (в другом терминале).

### 1. Приветствие по UDP

```bash
python lab1_udp/server.py
python lab1_udp/client.py
```

Сервер получает `Hello, server` и отвечает `Hello, client`.

### 2. Квадратное уравнение по TCP

```bash
python lab2_tcp/server.py
python lab2_tcp/client.py
```

На клиенте вводятся коэффициенты `a`, `b`, `c` уравнения
`a·x² + b·x + c = 0`; сервер считает дискриминант и возвращает корни.

### 3. Раздача HTML-страницы

```bash
cd lab3_http && python server.py
```

Затем открыть в браузере http://127.0.0.1:9085/ — сервер отдаст
содержимое `index.html`.

### 4. Многопользовательский чат

```bash
python lab4_chat/server.py
python lab4_chat/client.py      # запустить в нескольких терминалах
```

Первый ввод — имя пользователя. Сообщения видят все, кроме автора.
Выход из чата — команда `/quit`.

### 5. Веб-сервер: журнал оценок (GET/POST)

```bash
python lab5_web/server.py
```

Открыть http://127.0.0.1:9086/ — форма вносит дисциплину и оценку,
а ниже выводится журнал, сгруппированный по дисциплинам.

Остановить сервер — `Ctrl+C` в его терминале.
